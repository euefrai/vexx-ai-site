# Vexx-AI Interactive Website

A premium, production-ready interactive website for **Vexx-AI**, built with Next.js 14, TailwindCSS, and Framer Motion.

## 🚀 Features

- **Apple-Style Aesthetics**: Premium design with glassmorphism, smooth gradients, and micro-interactions.
- **Interactive Simulations**:
  - Live Command Center demo on the Home page.
  - Full Dashboard simulation with real-time performance metrics.
  - Remote Bridge phone mockup with interactive cursor.
- **Scroll-Based Storytelling**: Interactive visual explanation of the AI reasoning loop.
- **Responsive & Optimized**: Mobile-first design with SEO best practices.

## 🛠️ Tech Stack

- **Framework**: [Next.js 14](https://nextjs.org/) (App Router)
- **Styling**: [TailwindCSS](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **State Management**: React Hooks & Local State

## 📦 Getting Started

### Prerequisites

- Node.js 18.x or later
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone <your-repo-url>
   cd vexx-ai-site
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

## 🔐 Security & Privacy

Vexx-AI follows a **Local-First** philosophy. This website reflects those values by explaining our security model, user-owned API keys, and safe execution environment.
